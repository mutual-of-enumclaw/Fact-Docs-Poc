Importing and Exporting XML Files with PPSTo import and export XML files into Documaker Workstation, you must modify your INIMODIFYINGINIfiles. Transforming XML FilesYou can export an XML file with XSLT transformation. This lets you transform the outputTRANSFORMINGXML file into another format, such as HTML or text. The final output format isXML FILESdetermined by the XSLT template you choose.You can transform XML files using...• A DLL file (XSLTW32.DLL)• An EXE file (XSLTW32.EXE)Both transform the XML export file using the XSL style sheet specified in XSLTName INIoption. To use the EXE file, set the UseInProcess option to Yes. The system looks forthe XSLTW32.EXE file in the DLL directory. To use the DLL file, set the UseInProcessoption to No.To enable the export, add this option to the ExportFormats control group:< ExportFormats >01 =;MX;Export with XSL;WXMW32->WXMExportWithXSLThen add these options:< ExportWithXSL:MX >XSLTName=Executable=Debug=< ExportWithXSL >XSLTName=UseInProcess =Debug=OptionDescriptionXSLTNameThe full or relative path and name of the XSLT template.Executable(optional) The full path and name of the program. If omitted, the currentdirectory is used (where the AFEMNW32.EXE program is running).Debug(optional) Enter Yes to send debug output to a trace file.Appending outputYou can append multiple XSLT output transformations to the same file using this INItransformationsoption:< ExpFile_CD >AppendedExport = YesNOTE:The default control group used by the WXMExportWithXSL rule is theExportWithXSL control group.
