When the AOM needs to be replaced due to a correction

 

  1. Exela will provide the following files

AOMCLINDEXyyyymmdd.txt

The contents of this file.  You can edit this file, but only change the yyyymmdd.

 

COM – Affidavit of Mailing Detail - Novitex     AOMCLREPORTyyyymmdd.pdf 16      yyyymmdd

 

AOMCLREPORTyyyymmdd.pdf

This file is the actual AOM report

Do not change the contents.

The yyyymmdd should match the index file name and contents

 

 

  1. If replacing the AOM, provide information or a screen print to the OnBase tech to indicate the target report.
  2. Send files and screen print to OnBase (Lynda Poling) for replacement.
  3. If the AOM is brand new – check with OnBase to see if the new report has been ingested automatically.
