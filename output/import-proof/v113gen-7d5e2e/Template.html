Chapter 2Software Development PoliciesOutlined below is a description of the software distribution policies and an explanationOVERVIEWof the terms we use. Skywire Software has several product distributions each year.These distributions are calledreleasesandpatches.SYSTEMRELEASESTo continually improve and support the product, software enhancements andcorrections are organized into regularly scheduled system releases. Releases arenoted with a major and minor version number, such as 11.1 or 11.2.Each new release includes numerous changes and enhancements, but releases withmajor version number changes, such as release 10.0 and 11.0, tend to berevolutionaryin nature, with more major new features. These releases often require updateddocumentation. Releases with minor version number changes, such as 11.1, are moreevolutionaryin nature, with fewer major changes and more incremental enhancementsof existing features. All system releases undergo comprehensive unit and systemtesting.System releases are sent to each eligible customer on a CD or via the Internet, alongwith detailed information about the new enhancements and corrections. Registeredcustomers can access product installations via the DOSS web site at:www.skywiresoftware.com/dossSYSTEMPATCHESIn critical situations, a correction to the current system release can be made availableas a system patch, also known as a PTF or Program Temporary Fix.System patches are specific corrections to affected executable and source codemodules in a system release. Skywire Software Support typically distributes systempatches electronically (via email or FTP) or on CD. In either case, Skywire SoftwareSupport coordinates the delivery of a patch to those customers affected by the patch.NOTE:System patches are accumulated and sent with system releases as necessary.When installing patches, youmustapply all sequentially numbered patchesthat apply to your product license to continue to be eligible for support. Due toDLL dependencies, Skywire Software cannot support selectively appliedpatches.System patch reports and updated installations are also available from theDOSS web site.20
