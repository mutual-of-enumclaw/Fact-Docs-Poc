TO REMOVE A TABLE FROM THE AUTOMATIC TABLE DOWNLOAD PROCESS FROM POINT

 

  1. Remove POINT table name from POINT Table TBLFILE.
  2. Remove the actual file from QDLS/TABLES folder in the POINT environment.
  3. Remove the table file from the DocProd MRL.

 

 

TO ADD A NEW POINT TABLE TO THE AUTOMATIC TABLE DOWNLOAD PROCESS FROM POINT

 

  1. Add the POINT table name to the POINT Table TBLFILE.
  2. Manually add the table file to the DocProd MRL.  This is necessary for RUNDAPNET to work the first time the new table is available for TABLE refresh.
