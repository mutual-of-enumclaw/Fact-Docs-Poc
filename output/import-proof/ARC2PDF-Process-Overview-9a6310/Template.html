Migration process

 

The Master Resource Library (MRL) where this process is initiated from is called ARC2PDF (see highlighted folder below).

 

It is separate from the current DocProd MRL called MOEC0 (see highlighted folder below).

 

The Migration process will access existing Forms and Images from the current DocProd MRL.

This is controlled by the separate set of INI files that resides in the ARC2PDF start-in folder.

 

 

The manual process is described as follows.

 

ASSUMPTIONS

  • Each Archive row has a RUNDATE.
  • The ARCRET utility command can be run in a variety of ways.
    • Create 1 set of files for GENPRINT, run 100 transaction that have not been processed.
    • Create multiple sets of files
      • Typically done when only a RUNDATE range is specified
      • A variable number of sets of files is generated
      • The powershell script will process each set
  • Output PDF’s will be generated in the ARC2PDF folder system so as not to disturb the current Production MRL.
  • This process is controlled by a Powershell script.

 

 

INIT – Accept before/after RUNDATE values, set global variables

Step 1 – Based on the RUNDATE values received, Run ARCRET to extract data from the archive.

Uses FILTERAPPIDX.DAL script to assist in the APPIDX row selection.

MIGIND is blank or NULL

 

Step 2 – Create ARCRET.DIR to list all the unique names for the data sets obtained in Step 1.

Step 3 – Process the file sets listed in the ARCRET.DIR

Rename and Move the 4 files to the DATA folder

Run GENPRINT to create the PDF’s and metadata log files.

Prefix tag ERRFILE.DAT, LOGFILE.DAT and CUSMultiFilePrint.log with the ARCRET file name.

Clear files from the DATA folder in preparation for the next set.

After all ARCRET files are processed, combine these files into a single file for each

ERRFILE.DAT

LOGFILE.DAT

CUSMultiFilePrint

 

Step 4 – Move files around

Create a TEMP folder in ARC2PDF_BK folder

Move all files that were generated from the ARCRET process in Step 1.

Move the ARCRET.DIR

Move ARCRET.LOG

 

 

Step 5 – FILTERLOGFILE – Separate the PDF’s into those going to OnBase and those which will be excluded or have GENPRINT errors

Run FILTERLOGFILE

Run MOVETOEXCLUDED.BAT to move the files to the EXCLUDED folder in the backup folder.

Run MOVETOERROR.BAT to move the files to the ERROR folder in the backup folder.

 

Step 6 – Stage the files going to OnBase into a specific OnBase staging folder

Step 7 – Run SQL Updates file to mark the APPIDX rows as processed

Step 8 – Process wrap-up.  Send email with summary of results to the email distribution list.
