Once this is complete, thefile is closed and is not accessed again for processing.• After loading the field name arrays, the RECFILE.INI isopened. This file will be read one line at a time until the EOF.• Positions one to nineteen will be extracted and stored. Theremaining string will then be parsed looking for commas. Thenumber of commas will determine the number of copybooksthat are associated with that record. The individual copy-books will be extracted and stored in an array. This array willthen be processed.• The name of the copybook will be extracted from the arrayand then that copybook file will be opened. The copybook filewill be read one line at a time and each line will be processed.If the line contains an "*" in column seven, the line will beomitted because it is only a comment. Otherwise, the stringwill be parsed and the field name and length extracted andstored in an array.• Once every line for that copybook has been read and pro-cessed, the array (containing the field names and lengths)that was extracted from the copybook will be processed.©Copyright 2008 CSC. CS CO F F S / D D F F i le U t i li t yChapter 1Program Processing• The field names, the lengths, and any associated switches forthat field will be pulled from the arrays. The field name willbe compared to names loaded from the OFSFLDNM.TBL file.• If the field is found in that list and there is a correspondingdocument variable field name, then a record will be added tothe offsfile. Otherwise, a record will be added to the reportfile.• Once all entries in the array are processed, the program willread in the next copybook, or if that was the last copybookfor that current data extract record, the next record in theRECFILE.INI file will be read and processing will continue asmentioned above.• The offsfile.DAT, offsfile.DDF, and report.DAT files will have aname generated each time the program is executed. The nameof the offsfile will be OFF, followed by the current time inHHMMSS format. There will be one with a DAT extension andone with a DDF extension. Offsfile.DAT will contain the offset,the length, and the document variable field name. Offsfile.DDFwill contain the information needed for a Data Dictionaryentry. The file is delimited by semicolons and contains therecord name, field name, length, and several constant fields.• Only the records that have a match in the OFSFLDNM file willbe written to the OFFXXXXXX.DAT and OFFXXXXXX.DDF files.• The report file will be designated with an "R" followed by theHHMMSS format and will have a DAT extension. The time willonly be received once. Therefore, the time value will be thesame for all files for a single execution.• The report file will be a listing of all the records that did nothave a matching entry in OFSFLDNM or that had an entry butno document variable field name associated with it.• All input files must reside in the same directory as the pro-gram.
