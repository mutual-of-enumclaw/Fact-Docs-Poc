How to Unlock a Locked WIP Transaction

 

Login to the Stand Alone module of Media Management:

https://mediamgmt-prd.mutualofenumclaw.com/MMC0MOEScriptMain/MMLogin.aspx

ID = sysadmin

PW = syspwd

 

Select CONFIG = MOE

Click on: WIP Admin (from list on the left of the screen)

 

 

From the pop up window under Record Modify Date: select and earlier date than today so older records can be picked up, otherwise it is only looking at documents locked today.  

 

Enter the policy number (no module) in either the DocNumid: field

 

Click on the Search Button    

 

When results are returned, verify it is the correct record with correct User Id to be unlocked.  Sometimes there can be multiple records returned.

 

 

Click on the record line and it should open up with a delete button available.

 

 

Click the Delete button to unlock wip.

 

Notify the user that the WIP should be unlocked.
