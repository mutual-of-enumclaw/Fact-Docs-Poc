DocProd Checklist

Add a New Form to DocProd

 

OVERVIEW

Products will provide WORD docs for the new forms to be added to DocProd.  They are usually forms with new edition dates for existing forms in the DocProd system.

We must convert the WORD doc into FAP format and implement it into DocProd.

This checklist will provide a step by step process guideline.

Assign a FAP name to the new form. Typically, use the form name + “A”.  Ex: AA1234A

 

Duplicate the existing form line and increment the version letter

Assign a FAP name to the new edition date of the form.  Typically, use the form name + “incremented version Letter”.  Ex: AA1234B

 

Also, some of the CSC base system forms did not use the full form name.  Ex.A1234A.DAP instead of CA1234A.FAP.  Take this opportunity to switch from a single letter to the full form name.

 

All the columns in the spreadsheet should be filled in using data from Products, ALR and DocProd.
