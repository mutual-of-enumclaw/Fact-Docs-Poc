You need to have python and pip installed.

Then install:
pip install langchain langchain-community langchain-openai openai chromadb tiktoken unstructured chromadb

I had problems getting everything installed at once. If you run into trouble, install the packages one by one.

And don't forget to update your own API key in constants.py.
